# Little North

A small, atmospheric, third-person Arctic fox exploration game.

**Status:** preproduction · Phase A art calibration in progress.

**Visual direction:** Sculpted Arctic Storybook — handcrafted snow, soft faceted rock, sculpted snow-laden spruce, warm shelter, restrained Arctic light.

**Phase A goal:** a real Three.js browser scene, single-reference procedural spruce reconstruction with visual QA, a cozy cabin, arctic fox scale proxy, and camera / navigation controls. No production release without visual review.

See the Phase A branch for the initial prototype; this default branch intentionally remains minimal until reviewed.
